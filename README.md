# LexPilot AI

LexPilot est une plateforme IA pour cabinets d'avocats.

Objectif : devenir un collaborateur numerique capable de gerer les clients, dossiers, documents, mails, echeances et analyses IA.

## Modules actuels

- API .NET
- Clean Architecture
- Blazor Web
- Module Clients
- Module Documents
- LexPilot.AI
- Copilot IA en cours
